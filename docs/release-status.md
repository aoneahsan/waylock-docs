# Is Waylock available yet?

Waylock is in development. The Android app is not listed on Google Play yet.

The team is checking the signed release on devices, external services, account flows and Play submission. This page will change when a public listing and the released app have been verified. Until then, the guides explain planned controls; they are not a claim that you can install or use them today.

If you need a current update, [contact the Waylock team](mailto:aoneahsan@gmail.com).
