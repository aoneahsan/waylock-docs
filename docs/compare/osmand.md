# Moving from OsmAnd to Waylock

Checked on 7 November 2026. An offline map and navigation app built on OpenStreetMap. See <a href="https://osmand.net" target="_blank" rel="noopener noreferrer nofollow">OsmAnd</a> for its own details.

## How do they differ?

**OsmAnd is the better fit if you want:**

- A free version, offline maps and open data.

**Waylock is ahead on:**

- Google Maps data with your chosen route kept on the map.

The [full comparison](https://waylock.aoneahsan.com/compare/osmand) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Install the signed APK from the [download page](https://waylock.aoneahsan.com/download). It needs Android 8.0 or newer.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep OsmAnd until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
