# Moving from Magic Earth to Waylock

Checked on 7 November 2026. A navigation app with offline use and a paid Premium licence. See <a href="https://www.magicearth.com" target="_blank" rel="noopener noreferrer nofollow">Magic Earth</a> for its own details.

## How do they differ?

**Magic Earth is the better fit if you want:**

- Offline navigation, plus truck and EV routing.

**Waylock is ahead on:**

- Stops by distance along the road.

The [full comparison](https://waylock.aoneahsan.com/compare/magic-earth) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Waylock is in internal testing. Public installation is not available yet.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep Magic Earth until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
