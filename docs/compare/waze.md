# Moving from Waze to Waylock

Checked on 7 November 2026. A community-reported driving app. See <a href="https://www.waze.com" target="_blank" rel="noopener noreferrer nofollow">Waze</a> for its own details.

## How do they differ?

**Waze is the better fit if you want:**

- Free, with traffic reports from other drivers.

**Waylock is ahead on:**

- More than one added stop on a route: Waze's help page says one.

The [full comparison](https://waylock.aoneahsan.com/compare/waze) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Install the signed APK from the [download page](https://waylock.aoneahsan.com/download). It needs Android 8.0 or newer.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep Waze until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
