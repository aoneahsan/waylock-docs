# Moving from Roadtrippers to Waylock

Checked on 7 November 2026. A road-trip planner that recommends things to see along your route. See <a href="https://roadtrippers.com" target="_blank" rel="noopener noreferrer nofollow">Roadtrippers</a> for its own details.

## How do they differ?

**Roadtrippers is the better fit if you want:**

- Must-see stops recommended along the way.
- Up to 150 stops a trip on Premium.

**Waylock is ahead on:**

- A request for a kind of place within a distance range.
- A route that stays on the map after a wrong turn.

The [full comparison](https://waylock.aoneahsan.com/compare/roadtrippers) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Install the signed APK from the [download page](https://waylock.aoneahsan.com/download). It needs Android 8.0 or newer.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep Roadtrippers until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
