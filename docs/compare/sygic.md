# Moving from Sygic GPS Navigation to Waylock

Checked on 7 November 2026. A GPS navigation app that works offline. See <a href="https://www.sygic.com/gps-navigation" target="_blank" rel="noopener noreferrer nofollow">Sygic GPS Navigation</a> for its own details.

## How do they differ?

**Sygic GPS Navigation is the better fit if you want:**

- Offline maps.

**Waylock is ahead on:**

- A delivery order with held stops.

The [full comparison](https://waylock.aoneahsan.com/compare/sygic) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Waylock is in internal testing. Public installation is not available yet.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep Sygic GPS Navigation until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
