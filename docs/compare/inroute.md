# Moving from inRoute to Waylock

Checked on 7 November 2026. A route planner for iPhone and iPad that factors in weather, elevation and curves. See <a href="https://apps.apple.com/app/id703796787" target="_blank" rel="noopener noreferrer nofollow">inRoute</a> for its own details.

## How do they differ?

**inRoute is the better fit if you want:**

- Weather and elevation along the route.
- A family plan on sale today.

**Waylock is ahead on:**

- An Android app.

The [full comparison](https://waylock.aoneahsan.com/compare/inroute) has both sets of prices and every feature row.

## How do I move across?

Waylock has no import from other apps yet, so this is a fresh start.

1. Install the signed APK from the [download page](https://waylock.aoneahsan.com/download). It needs Android 8.0 or newer.
2. Sign in with Google.
3. On the Trip planner, set where you start and finish, then ask for a stop by distance along the road.
4. Keep inRoute until you have tried a route.

Waylock's controls are built, and their device checks are still open. Google's navigation still does the guiding. [Route controls](/guide/route-controls) explains each one.
